# QR Code Full

Bem-vindo ao Repositório oficial do projeto QR Code Full, 
esse projeto junta duas funcionalidades em uma: Criação de QR Code e Leitura do mesmo.
Além disso, da para personalizar o tamanho e cores do código QR.

Feito por Antonio Henrique de Andrade e Paulo Haruo Magalhães Amemyia
